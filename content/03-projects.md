# Public GitHub projects

Estos cuatro proyectos existen en los repositorios públicos de GitHub de Ana Paula. Las descripciones se limitan a la información publicada en sus README; no afirman métricas ni resultados adicionales.

## 42-Transcendence
<!-- status:approved -->
Aplicación web full stack de Pong con autenticación, perfiles, partidas en tiempo real mediante WebSockets y despliegue con Docker Compose y Nginx.

Repositorio: https://github.com/anapaulapgavilan/42-Transcendence

## 42-Cub3d
<!-- status:approved -->
Proyecto en C que renderiza un laberinto en primera persona mediante raycasting y valida mapas, texturas y posición inicial.

Repositorio: https://github.com/anapaulapgavilan/42-Cub3d

## 42-Minishell
<!-- status:approved -->
Shell simplificada en C compatible con POSIX, con parser propio, pipes, redirecciones, comandos integrados y manejo de señales.

Repositorio: https://github.com/anapaulapgavilan/42-Minishell

## 42-WebServ
<!-- status:approved -->
Servidor HTTP/1.1 en C++98 con hosts virtuales, E/S no bloqueante mediante poll() y soporte para CGI.

Repositorio: https://github.com/anapaulapgavilan/42-WebServ
